# Prompt for Google Stitch / UI Generator

Copy and paste the following prompt into Google Stitch (or any other AI UI generation tool like v0, Cursor, etc.) to generate the frontend Next.js interface for this project:

---

**Prompt:**

Build a modern, highly aesthetic, and dynamic frontend UI for an **AI-Powered Restaurant Recommendation System**. 

**Framework:** Next.js (React), using TailwindCSS for styling if possible.
**Theme:** Light theme. Use a curated, harmonious color palette with smooth gradients, glassmorphism effects (translucent panels with subtle borders), and clean micro-animations (e.g., smooth hover effects, fade-ins). The design must feel extremely premium, responsive, and state-of-the-art. Please use a modern Google Font (like Inter, Outfit, or Roboto).

**The UI should consist of the following main sections:**

1. **Header/Hero Section:**
   - A catchy title: "Gourmet AI - Restaurant Recommender"
   - A subtle, beautiful background or pattern.

2. **Preference Input Form (Sidebar or Top Container):**
   - **Location:** A dropdown select (Options: Anywhere in Bangalore, Indiranagar, Koramangala, Whitefield, Jayanagar, HSR Layout).
   - **Budget:** Radio buttons, chips, or a select dropdown (Low, Medium, High).
   - **Cuisine:** A multi-select dropdown or clickable pills (North Indian, Chinese, Italian, South Indian, Fast Food, Desserts).
   - **Minimum Rating:** A slider or dropdown (Range: 3.0 to 5.0).
   - **Additional Preferences:** A text input for custom needs (e.g., "family friendly", "rooftop seating").
   - **Call to Action:** A prominent "Get Recommendations" button that supports a loading/spinning state.

3. **Recommendations Results Area:**
   - When loading, show a skeleton loader or a beautiful glowing animation.
   - Once loaded, display a grid or list of **Restaurant Cards**.
   - **Card Details:** Each card should beautifully present the Restaurant Name, Cuisine Tags, Star Rating, and Estimated Cost.
   - **AI Explanation Box:** Inside or attached to each card, include a distinct, highlighted section titled "Why this?" containing an AI-generated explanation of why it matched the user's preferences.
   - **Feedback Mechanism:** At the bottom of each card, include interactive thumbs-up (👍) and thumbs-down (👎) buttons so users can rate the recommendation.

Please populate the UI with realistic placeholder data so I can see how it looks in its final state. Do not use generic plain colors; make it look like a polished, production-ready startup product.
